# Aion2MarketManager

Aion2MarketManager помогает сравнить варианты, посчитать расходы и разобраться во вложенных рецептах.

Приложение работает на Windows. Интерфейс — на русском, названия предметов и профессий — как в Global EU.

## Возможности

- Список ингредиентов и стоимость крафта с раскрытием вложенных рецептов.
- Сравнение покупки и самостоятельного изготовления, когда хватает данных.
- Расчёты расходов на партии и вероятностные исходы.
- Мастерство профессий: **Novice 1–50** и **Professional 1–50**.
- Игровые иконки по Item ID с локальным кэшем.
- Настройки и база данных, которые остаются на компьютере.

## Скачать и запустить

**Актуальный выпуск — Beta 1.4.10 (Windows Portable).** Приложение работает без установки Python. Локальный HTTP-сервер выбирает свободный порт, не занимая порт 8765 по умолчанию.

**[Скачать последнюю версию для Windows](https://github.com/Shinokodomo/Aion2MarketManager-Releases/releases/latest)**

1. В разделе **Assets** скачай `Aion2MarketManager-Windows-Portable.zip` — полный архив для первой установки.
2. Распакуй его в отдельную папку, куда у тебя есть доступ на запись.
3. Запусти `Aion2MarketManager.exe`. Python устанавливать не нужно. Аккаунт GitHub тоже не требуется.

Файлы с названием `Delta-from-...` предназначены для встроенного обновлятора, а не для первой установки.

## Обновления

Когда выйдет новая версия, приложение предложит установить её при запуске. Можно нажать «Позже» и вернуться к обновлению в настройках. После обновления покажем «Что нового».
