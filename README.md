# Aion2MarketManager

Крафтишь предметы в **Aion 2** и хочешь понять, стоит ли тратить материалы или проще купить готовое на аукционе? Aion2MarketManager помогает сравнить варианты, посчитать расходы и разобраться во вложенных рецептах.

Приложение работает на Windows. Интерфейс — на русском, названия предметов и профессий — как в Global EU.

## Возможности

- Список ингредиентов и стоимость крафта с раскрытием вложенных рецептов.
- Сравнение покупки и самостоятельного изготовления, когда хватает данных.
- Расчёты расходов на партии и вероятностные исходы.
- Мастерство профессий: **Novice 1–50** и **Professional 1–50**.
- Игровые иконки по Item ID с локальным кэшем.
- Настройки и база данных, которые остаются на компьютере.

## Скачать и запустить

Готовые Windows-версии размещаются в [Releases](https://github.com/Shinokodomo/Aion2MarketManager-Releases/releases).

Скачай `Aion2MarketManager-Windows-Portable.zip`, распакуй в отдельную папку и запусти `Aion2MarketManager.exe`. Python устанавливать не нужно.

## Обновления

Когда выйдет новая версия, приложение предложит установить её при запуске. Можно нажать «Позже» и вернуться к обновлению в настройках. После обновления покажем «Что нового».

При обновлении сохраняются папки `data`, `backups`, `exports` и `logs`. Первая установка обновлений через GitHub ещё проходит тестирование.
